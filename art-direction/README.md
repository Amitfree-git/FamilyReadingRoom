# FamilyReadingRoom 原创高清原画规范

当前 **30 课美术分镜规划已经完成**；这不代表原画已经绘制或发布。只允许通过人工审核及像素检测的成品切换到线上。

### 三类必须单独制作的原画

| 素材 | 像素 | 比例 |
|---|---:|---:|
| 桌面课程封面 | 2560×1120 | 16:7 |
| 手机专用封面 | 1200×900 | 4:3 |
| 每幅独立历史漫画 | 1600×1000 | 8:5 |

全套30课对应30张电脑主图、30张手机主图和92张独立分镜，共 **152 张独立原画**。不允许把小图放大、从低分辨率总拼图切割或把相似角色改色后重复使用。

每课美术场景见 lessons.json。画面内不生成汉字、气泡、UI或水印；人物、朝代、建筑和器物要符合所选历史背景。寓言与历史记载分开表述，人物保持跨分镜面相与衣装一致。

桌面采用宽屏主画面，手机使用重新构图的竖幅，平板居中裁切；分镜桌面4列、平板2列、手机1列。使用独立的HTML字幕，不把文字放到图片中。图片输出WebP高质量并保留PNG母版。

素材按 docs/art/hd/c01/cover-desktop.webp、cover-mobile.webp、scene-01.webp 命名，并按课程ID分文件夹。

执行 python scripts/check_original_art.py 检查图片尺寸和数量。自动像素检测无法代替清晰度、历史准确性与美术质量的人工审阅。

当前网站仍然使用已发布的旧插图，尚未把规划中的占位图片作为实际图片发布。
